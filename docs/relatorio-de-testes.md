# Relatório de Testes — SauceDemo

## 1. Objetivo
O objetivo deste projeto foi aprimorar a execução de testes manuais, validando o funcionamento das principais funcionalidades do sistema e identificando possíveis comportamentos inesperados que possam impactar a experiência do usuário.

## 2. Escopo dos testes
Nos testes foram executadas diversas funcionalidades, incluindo login, lista de produtos, ordenação de produtos, carrinho de compras, checkout e finalização de compras.

## 3. Ambiente de teste
O projeto foi executado no sistema operacional Windows, utilizando o navegador Google Chrome.

## 4. Resumo da execução
Durante a execução dos testes, os 25 casos de teste foram executados e aprovados, não sendo identificados casos com status Fail ou Blocked.

## 5. Resultados
De acordo com os testes executados, as funcionalidades avaliadas apresentaram o comportamento esperado, sem ocorrência de falhas durante a execução dos casos de teste.

## 6. Conclusão
A execução dos testes permitiu validar as principais funcionalidades do sistema dentro do escopo definido. Os 25 casos de teste foram executados com sucesso, apresentando os resultados esperados e sem ocorrência de casos com status Fail ou Blocked. A atividade também contribuiu para a prática de testes manuais, documentação dos resultados e identificação de comportamentos do sistema sob diferentes cenários.
