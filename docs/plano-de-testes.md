# Plano de Testes — SauceDemo

## 1. Objetivo

Validar o funcionamento das principais funcionalidades da aplicação SauceDemo através de testes manuais.

O objetivo é identificar possíveis comportamentos inesperados, registrar os resultados dos testes e documentar possíveis defeitos encontrados.

## 2. Aplicação

**Nome:** SauceDemo

**URL:** https://www.saucedemo.com/

**Tipo:** Aplicação web de e-commerce

## 3. Escopo dos testes

Serão testadas as seguintes funcionalidades:

* Login
* Catálogo de produtos
* Ordenação de produtos
* Carrinho de compras
* Checkout
* Finalização da compra

## 4. Fora do escopo

Não serão realizados neste projeto:

* Testes de performance
* Testes de carga
* Testes de segurança aprofundados
* Testes de API
* Testes automatizados

## 5. Tipos de testes

Serão utilizados:

* Testes funcionais
* Testes positivos
* Testes negativos
* Testes exploratórios
* Testes de fluxo
* Validação de mensagens de erro

## 6. Ambiente de testes

**Sistema operacional:** Windows

**Navegador:** Google Chrome

**Tipo de execução:** Testes manuais

## 7. Critérios de entrada

Os testes poderão ser iniciados quando:

* A aplicação estiver disponível.
* O navegador estiver funcionando.
* As credenciais de teste estiverem disponíveis.
* O ambiente estiver acessível.

## 8. Critérios de saída

A execução será considerada concluída quando:

* Todos os casos de teste planejados forem executados.
* Os resultados forem registrados.
* Os casos com falha forem analisados.
* Os bugs encontrados forem documentados.
* As evidências necessárias forem anexadas.

## 9. Severidade dos bugs

### Critical

Defeito que impede completamente uma funcionalidade essencial ou o uso da aplicação.

### High

Defeito que impede uma funcionalidade importante, mas não necessariamente toda a aplicação.

### Medium

Defeito que afeta uma funcionalidade, porém existe uma alternativa ou o impacto é limitado.

### Low

Defeito de baixo impacto, como pequenos problemas visuais ou comportamentos pouco relevantes.

## 10. Entregáveis

Ao final do projeto serão disponibilizados:

* Plano de testes
* Cenários de teste
* Casos de teste
* Evidências
* Relatórios de bugs
* Relatório final de execução
