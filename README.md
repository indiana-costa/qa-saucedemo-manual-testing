# 🧪 QA Manual Testing — SauceDemo

Projeto de testes manuais desenvolvido com o objetivo de praticar e demonstrar conhecimentos em **Quality Assurance (QA)**, incluindo planejamento, criação de casos de teste, execução, documentação e análise dos resultados.

## 🎯 Objetivo

Validar as principais funcionalidades da aplicação SauceDemo por meio de testes manuais, utilizando diferentes cenários positivos e negativos e documentando os resultados obtidos durante a execução.

## 🌐 Aplicação testada

**SauceDemo** — aplicação web de demonstração de e-commerce.

🔗 https://www.saucedemo.com/

## 🔍 Escopo dos testes

Foram avaliadas as seguintes funcionalidades:

* Login
* Lista de produtos
* Detalhes dos produtos
* Ordenação de produtos
* Adição e remoção de produtos do carrinho
* Navegação do carrinho
* Checkout
* Validação de campos obrigatórios
* Resumo do pedido
* Finalização da compra

## 🧪 Tipos de testes

* Testes funcionais
* Testes positivos
* Testes negativos
* Testes exploratórios
* Testes de fluxo
* Validação de mensagens de erro

## 📊 Resultado da execução

Foram executados **25 casos de teste**.
