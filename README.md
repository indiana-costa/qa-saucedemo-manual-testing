QA Manual Testing — SauceDemo

📌 Sobre o projeto

Projeto de Quality Assurance desenvolvido para praticar testes manuais em uma aplicação de e-commerce.

O objetivo é testar os principais fluxos da aplicação, criar casos de teste, executar os testes, registrar resultados e documentar possíveis defeitos encontrados.

🎯 Objetivo

Validar o funcionamento das principais funcionalidades da aplicação SauceDemo através de testes manuais.

🌐 Aplicação testada

SauceDemo

https://www.saucedemo.com/

🧪 Funcionalidades testadas

* Login
* Catálogo de produtos
* Ordenação de produtos
* Carrinho de compras
* Checkout
* Finalização da compra

🔍 Tipos de testes

* Testes funcionais
* Testes positivos
* Testes negativos
* Testes exploratórios
* Testes de fluxo
* Validação de mensagens de erro
